# v0.8 Virtual Portfolio Paper Trader

## Scope

- XAUUSD and GBPUSD only (the two symbols that passed the 70,000-bar validation)
- simultaneous independent virtual positions
- persistent balance and open-position state across restarts
- spread, slippage, commission, stop-loss, take-profit and opposite-signal exits
- CSV closed-trade journal and on-demand JSON performance report
- no MT5 order-submission call in the virtual-paper engine

## Safety boundary

`portfolio-observe` requires `mode: paper` and `enable_order_submission: false`.
It creates virtual records only. It does not place demo or live orders.

## Windows upgrade

Stop the old observer with Ctrl+C, replace the project files with this version,
then run:

```powershell
cd "D:\Gold Bot\gold_mt5_bot"
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest -q
Copy-Item config.paper.v08.example.yaml config.paper.v08.yaml
python -m goldbot.cli portfolio-observe --config config.paper.v08.yaml --once
python -m goldbot.cli portfolio-observe --config config.paper.v08.yaml
```

The first cycle establishes a forward-only baseline. It intentionally does not
manufacture a trade from candles that occurred before v0.8 started.

## Results

In another PowerShell window:

```powershell
cd "D:\Gold Bot\gold_mt5_bot"
.\.venv\Scripts\Activate.ps1
python -m goldbot.cli paper-report --config config.paper.v08.yaml
Get-Content logs\paper_trades_v08.csv -Tail 20
```

Review operation after 24 hours, preliminary performance after 7 days, and make
no demo-execution decision before at least 30 days and 100 closed virtual trades
per symbol. Historical and paper results do not guarantee future returns.
