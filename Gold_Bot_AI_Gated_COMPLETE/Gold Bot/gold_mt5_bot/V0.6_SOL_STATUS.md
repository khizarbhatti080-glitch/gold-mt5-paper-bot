# v0.6 Solana Research Status

- Added broker-aware Solana symbol discovery (`find-symbol`).
- Added an isolated Solana configuration template.
- Reuses the unchanged M15 London FVG inversion + EMA50 + 2.5R strategy.
- Uses chronological 70/30 in-sample/out-of-sample validation.
- Keeps order submission disabled.
- Gold configuration and historical results remain unchanged.

An actual SOL result is intentionally not claimed in this package. It must be
produced from the user's broker history so symbol naming, spreads, point size,
and available candles match the execution venue.
